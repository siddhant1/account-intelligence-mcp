# Tool reference

> Generated by `npm run docs:tools` from the live tool definitions. Do not edit by hand.

Every tool returns its result twice: as `structuredContent` (validated against the output schema below) and as a JSON
`text` block for clients that do not support structured output. Failures return `isError: true` with a JSON body:

```json
{ "error": { "code": "NOT_FOUND", "message": "Company cmp_9999 was not found", "hint": "Use search_companies to look up valid company IDs." } }
```

| Error code | Meaning |
| --- | --- |
| `INVALID_ARGUMENT` | Input passed the schema but is not valid (for example an unknown country). Schema violations are reported by the SDK as `Input validation error: ...`. |
| `NOT_FOUND` | A referenced company or contact does not exist. The hint says which tool finds valid IDs. |
| `FORBIDDEN` | The API key lacks the scope this tool needs. |
| `INTERNAL` | Unexpected server failure. Details are logged server-side, never returned. |

## `search_companies`

**Search companies**: Search the company database by free text and filters. Text matches company name, industry, description and tags with relevance ranking; filler words such as "companies" are ignored and shorthand like "AI" or "fintech" is expanded. Returns compact summaries; call get_company for full details or search_contacts to find people.

- Required scope: `companies:read`
- Annotations: `readOnlyHint: true` · `idempotentHint: true` · `openWorldHint: false`

### Input

| Field | Type | Required | Constraints | Description |
| --- | --- | --- | --- | --- |
| `query` | string | no | 1-200 chars | Free-text query, e.g. "AI companies", "payments", "computer vision". Omit to list by size. |
| `country` | string | no | 2-60 chars | Country name or ISO code, e.g. "Australia" or "AU" |
| `industry` | string | no | 2-60 chars | Industry filter (partial, case-insensitive), e.g. "Fintech", "Healthcare", "Artificial Intelligence" |
| `minEmployees` | integer | no | ≥ 1 | Minimum headcount (inclusive) |
| `maxEmployees` | integer | no | ≥ 1 | Maximum headcount (inclusive) |
| `limit` | integer | no | ≥ 1, ≤ 50, default `10` | Maximum results to return (1-50, default 10) |

### Example

```jsonc
// tools/call arguments
{
  "query": "AI companies",
  "country": "Australia",
  "limit": 3
}

// structuredContent of the result

      "name": "Kookaburra AI",

      "city": "Brisbane"
    },
    {
      "id": "cmp_3",
      "name": "Southern Cross Analytics",
      "industry": "Artificial Intelligence",
      "employees": 210,
      "country": "Australia",
      "city": "Melbourne"
    },
    {
      "id": "cmp_17",

      "industry": "Legal Tech",

      "country": "Australia",
      "city": "Canberra"

  "total": 11
}
```

## `get_company`

**Get company details**: Get the full profile of one company: website, industry, headcount, location, founding year, description, tags and how many contacts are on file. Use an ID from search_companies.

- Required scope: `companies:read`
- Annotations: `readOnlyHint: true` · `idempotentHint: true` · `openWorldHint: false`

### Input

| Field | Type | Required | Constraints | Description |
| --- | --- | --- | --- | --- |
| `companyId` | string | yes | pattern `^cmp_\d{1,9}$` | Company ID returned by search_companies, e.g. "cmp_1" |

### Example

```jsonc
// tools/call arguments
{
  "companyId": "cmp_1"
}

// structuredContent of the result
{

  "foundedYear": 2016,
  "tags": [
    "B2B data",
    "sales intelligence",
    "AI",
    "data enrichment"
  ],
  "contactCount": 8
}
```

## `search_contacts`

**Search contacts**: Find people, optionally within one company, filtered by job title, seniority or department. Results are ordered most senior first. Contact details (email, LinkedIn) are not included; call enrich_contact for those.

- Required scope: `contacts:read`
- Annotations: `readOnlyHint: true` · `idempotentHint: true` · `openWorldHint: false`

### Input

| Field | Type | Required | Constraints | Description |
| --- | --- | --- | --- | --- |
| `companyId` | string | no | pattern `^cmp_\d{1,9}$` | Company ID returned by search_companies, e.g. "cmp_1" |
| `jobTitle` | string | no | 2-100 chars | Job title filter; every word must appear in the title (case-insensitive), e.g. "Engineer", "Head of Sales" |
| `seniority` | `"executive"` \| `"vp"` \| `"director"` \| `"manager"` \| `"senior"` \| `"individual_contributor"` | no |  | Seniority band |
| `department` | `"executive"` \| `"engineering"` \| `"product"` \| `"sales"` \| `"marketing"` \| `"operations"` | no |  | Department |
| `limit` | integer | no | ≥ 1, ≤ 100, default `25` | Maximum results to return (1-100, default 25) |

```jsonc
  "jobTitle": "Engineer"
```

## `enrich_contact`

**Enrich contact**: Look up verified contact details (work email, LinkedIn profile, phone) for one contact through the enrichment provider. Results are saved, so repeat calls for the same contact return the stored data. LinkedIn and phone can be null when the provider has no match. Only enrich contacts the user actually needs.

- Required scope: `contacts:enrich`
- Annotations: `readOnlyHint: false` · `destructiveHint: false` · `idempotentHint: true` · `openWorldHint: true`

### Input

| Field | Type | Required | Constraints | Description |
| --- | --- | --- | --- | --- |
| `contactId` | string | yes | pattern `^cnt_\d{1,9}$` | Contact ID returned by search_contacts, e.g. "cnt_1" |

### Example

```jsonc
// tools/call arguments
{
  "contactId": "cnt_3"
}

// structuredContent of the result
{
  "contactId": "cnt_3",
  "name": "Rohan Ryan",
  "email": "rohanr@signalgrid.example",
  "linkedin": "https://www.linkedin.com/in/rohan-ryan-facd49",
  "phone": null,
  "enrichedAt": "2026-01-15T09:30:00.000Z",
  "cached": false
}
```

## `export_contacts`

**Export contacts**: Export contacts to a CSV (default) or JSON file and return a signed, time-limited download URL that works without an API key. The file includes company and enrichment fields; contacts that were never enriched have empty email/LinkedIn columns, so call enrich_contact first if those are needed. Duplicate IDs are ignored.

- Required scope: `contacts:export`
- Annotations: `readOnlyHint: false` · `destructiveHint: false` · `idempotentHint: false` · `openWorldHint: false`

### Input

| Field | Type | Required | Constraints | Description |
| --- | --- | --- | --- | --- |
| `contactIds` | string[] | yes | pattern `^cnt_\d{1,9}$`, 1-1000 items | Contact IDs to export, e.g. ["cnt_1", "cnt_2"] |
| `format` | `"csv"` \| `"json"` | no | default `"csv"` | File format (default "csv") |

### Example

```jsonc
// tools/call arguments
{
  "contactIds": [
    "cnt_3",
    "cnt_7"
  ]
}

// structuredContent of the result

```
