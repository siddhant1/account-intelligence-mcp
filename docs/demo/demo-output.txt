▶ Input and output schema of search_companies (JSON Schema generated from Zod)
  Search the company database by free text and filters. Text matches company name, industry, description and tags with relevance ranking; filler words such as "companies" are ignored and shorthand like "AI" or "fintech" is expanded. Returns compact summaries; call get_company for full details or search_contacts to find people.
    field         type     constraints                description                                                 
    query         string   ≤200 chars                 Free-text query, e.g. "AI companies", "payments", "computer 
    country       string   ≤60 chars                  Country name or ISO code, e.g. "Australia" or "AU"          
    industry      string   ≤60 chars                  Industry filter (partial, case-insensitive), e.g. "Fintech",
    minEmployees  integer  min 1                      Minimum headcount (inclusive)                               
    maxEmployees  integer  min 1                      Maximum headcount (inclusive)                               
    limit         integer  min 1, max 50, default 10  Maximum results to return (1-50, default 10)                
  outputSchema: { results, total }
